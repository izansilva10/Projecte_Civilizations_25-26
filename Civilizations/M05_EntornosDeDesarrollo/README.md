# Civilizations

Juego de estrategia por consola donde gestionas una civilización medieval. Construye edificios, mejora tecnologías, recluta ejércitos y defiende tu territorio de oleadas enemigas que atacan cada pocos minutos. El objetivo es sobrevivir el mayor número de batallas optimizando recursos y unidades.

## Tecnologías utilizadas

| Capa | Tecnología |
|------|------------|
| Backend (lógica de juego) | Java  |
| Base de datos | SQL |
| Frontend web | Node.js + hbs + CSS3 |
| Control de versiones | Git + GitHub |

## Estructura del proyecto

## Instalación y ejecución

### Backend Java (M03)

1. Abre el proyecto en tu IDE (VS Code).
2. Asegúrate de que todos los archivos `.java` están en `M03_Programacion/civilizations/`.
3. Compila y ejecuta la clase `Main.java`.

### Base de datos (M02)

1. Conéctate a tu instancia de Oracle (SQL Developer, DBeaver o sqlplus).
2. Ejecuta el script `M02_BaseDeDatos/scripts/create_tables.sql`.
3. Las tablas quedarán creadas con las restricciones y claves foráneas.

### Aplicación web (M04)

1. Abre una terminal en la carpeta `M04_Web`.
2. Instala las dependencias:
   npm install
